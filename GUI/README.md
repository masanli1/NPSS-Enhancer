# GUI（v2.6）

```bash
./run_gui.command
# 或
python npss_gui.py
```

- 内容：音乐为主 / 声音为主。
- **多统计 Gmin（v2.6）**：默认开启；含 soft 跨区域拓扑 + 高/低贡献补全。
- 16k/48k 都走多统计；48k = 16k gate + 8k+ 保留。
- 输出保留**立体声**；左右声道分别处理。
- 音乐建议处理采样率选 **48k**；16k 会带限到 8k。
- 结果（16k）：音乐 13.83 / PESQ 2.498 / STOI 0.9086；声音 13.96 / PESQ 2.484 / STOI 0.9117。
- 高贡献 = 主干锚点；低贡献 = 辅助（补到 0.82，不满）；gate 仍连续。
- 48k：8k+ 不降噪，只保留；真立体声约 2× 计算。
