# GUI（v2.3）

```bash
./run_gui.command
# 或
python npss_gui.py
```

- 内容：音乐为主 / 声音为主。
- **多统计 Gmin（v2.3）**：默认开启。
- 16k/48k 都走多统计；48k = 16k gate + 8k+ 保留。
- 输出保留**立体声**；左右声道分别处理。
- 音乐建议处理采样率选 **48k**；16k 会带限到 8k。
- 48k 音乐低频保护：20–250 Hz 约 −1.05 dB（原来 −2.52）。
- 旧循环只对非多统计模式生效；多统计固定 3-pass/2-loop。
- 结果（16k）：音乐 13.77 / PESQ 2.487 / STOI 0.9071；声音 13.92 / PESQ 2.480 / STOI 0.9110。
- 48k：8k+ 不降噪，只保留；真立体声约 2× 计算。
