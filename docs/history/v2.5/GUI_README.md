# GUI（v2.5）

```bash
./run_gui.command
# 或
python npss_gui.py
```

- 内容：音乐为主 / 声音为主。
- **多统计 Gmin（v2.5）**：默认开启；含 soft 跨区域拓扑 + 支点补全。
- 16k/48k 都走多统计；48k = 16k gate + 8k+ 保留。
- 输出保留**立体声**；左右声道分别处理。
- 音乐建议处理采样率选 **48k**；16k 会带限到 8k。
- 48k 音乐低频保护：20–250 Hz 约 −1.01 dB。
- 结果（16k）：音乐 13.81 / PESQ 2.497 / STOI 0.9086；声音 13.95 / PESQ 2.484 / STOI 0.9117。
- 支点补全：前后 1–2 帧 + 相邻频点有支点时，按 `S` 阈值补缺失支点；不做音频恢复。
- 48k：8k+ 不降噪，只保留；真立体声约 2× 计算。
