# GUI（v2.4）

```bash
./run_gui.command
# 或
python npss_gui.py
```

- 内容：音乐为主 / 声音为主。
- **多统计 Gmin（v2.4）**：默认开启；含 soft 跨区域拓扑权重。
- 16k/48k 都走多统计；48k = 16k gate + 8k+ 保留。
- 输出保留**立体声**；左右声道分别处理。
- 音乐建议处理采样率选 **48k**；16k 会带限到 8k。
- 48k 音乐低频保护：20–250 Hz 约 −1.03 dB。
- 结果（16k）：音乐 13.79 / PESQ 2.492 / STOI 0.9085；声音 13.94 / PESQ 2.482 / STOI 0.9116。
- 48k：8k+ 不降噪，只保留；真立体声约 2× 计算。
