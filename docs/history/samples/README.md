# Samples

This repository includes a **synthetic** demo pair generated by `scripts/make_demo.py`; no third-party speech/music audio is shipped.

The demo pair is already included; regenerate it with:

```bash
python scripts/make_demo.py
```

Then try:

```bash
python npss_parallel.py samples/demo_noisy.wav samples/demo_denoised.wav --workers 1 --loops 5
```

For PESQ/STOI, use your own clean/noisy pairs:

```bash
python eval_official.py --clean data/val16/clean --noisy data/val16/noisy
```
