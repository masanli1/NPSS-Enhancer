# 人声特征提取与分离（v3.3）

> 降噪问的是“噪声有多稳定”；人声提取问的是“这一格像不像人在说话”。
> 这是两个不同的维度：v2.7 的多统计 Gmin 已经把“结构稳定性”这一维做到了头，
> 继续调阈值只是把同一件事做得更用力；v3.3 换到目标信号自己的特征上——
> 基频、谐波、共振峰、音节调制——再把这些特征当作掩码，乘在 NPSS 增益上。

纯 numpy，无模型、无训练；16 kHz 内部分析，输出回原采样率。
实现见 [`GUI/voice_sep.py`](../GUI/voice_sep.py)。

## 1. 特征

| 特征 | 怎么算 | 为什么是“人声” |
|---|---|---|
| 基频 F0 | 倒谱峰候选（每帧 3 个）+ Viterbi 平滑，70–360 Hz 先验，允许清/浊切换 | 嗓音只有一个基频；和弦/多音同时出现几个倒谱周期 |
| 谐波梳 | 按 F0 生成时变高斯梳齿，齿间留 `between`（默认 0.9） | 浊音的能量集中在谐波上，噪声不在 |
| 浊音度 | 无偏自相关峰（按窗自相关归一） | 绝对周期度；白噪/静音接近 0，音乐也高（所以不单独用它） |
| 共振峰 | 每 50 ms 一帧 LPC-16，Levinson–Durbin 求根，取 F1/F2/F3 | 声道形状是人声的“指纹”，用于报告和话音包络 |
| 音节调制 | 帧能量包络在 2–8 Hz 的占比 | 说话有 3–6 Hz 的音节节律；持续和弦/ drone 没有 |
| 长期话音谱 | 浊音帧的平均幅度谱 | 本段录音自己的音色基准 |

**语音核心（voice core）**：一帧要同时满足

```
harm > 0.24  &  mod > 0.18  &  voicing > 0.25  &  snr > -6 dB
```

才算是“人声核心”。核心帧向两侧扩张（前 100 ms、后 250 ms）成语音段，
清辅音就跟着它旁边的元音一起被放行；短于 80 ms 的孤立核心会被丢掉。

**音乐守卫**：如果整段浊音帧的调制中位数 < 0.10、2–8 kHz 谱平坦度 < 0.30、
谐波占比 > 0.45，说明这是一段“有音高但没有音节”的素材（纯 BGM），
整段直接落到地板。带人声的歌不会被这条规则命中（歌词本身有音节调制）。

## 2. 分离

```
G        = G_npss × G_voice
G_voice  = [ floor + (1 - floor) × VAD × ( v·comb + (1 - v) ) ] ^ strength
```

- `G_npss`：v2.7 多统计 Gmin（结构稳定性），负责语音质量不倒退；
- `floor`：非语音格的下限，默认 −40 dB；
- `comb`：`between + (1-between)·H`，浊音段只留谐波梳，齿间压到 −20 dB 左右；
- `v`：浊音度；清音帧走全通，交给 `G_npss` 和 VAD；
- `strength`：GUI 的“人声强度”，0–1，整体缩放人声门。

停顿时 VAD=0，输出接近静音；浊音段按谐波梳保留；清辅音跟着语音段通过。
这就是“把除人声之外的声音压下去”的可执行版本：噪声、机器声、纯音乐在
没有人声的格子里被压到地板；人声所在的格子按谐波结构保留。

## 3. 结果

### 3.1 语音质量（42 对 VoiceBank-DEMAND，16 kHz，48k 源重采样）

固定步长抽样（`files[::19][:42]`，可由下面的脚本逐字复现），同一批文件、
同一套指标，只换后端：

| 方法 | SI-SDR | PESQ-WB | STOI |
|---|---|---|---|
| noisy | 8.60 | 1.950 | 0.9270 |
| 多统计 music（v2.7 默认） | 13.67 | **2.351** | **0.9226** |
| 多统计 voice（+40% NMF） | 13.69 | 2.330 | 0.9235 |
| **人声提取（v3.3.2）** | **13.93** | 2.337 | 0.9207 |

- SI-SDR +0.27 dB 相对 v2.7 默认；PESQ 低 0.006、STOI 低 0.002，属于同一水平
  （这批 42 对的抽样噪声就有这个量级，见逐文件表）。
- 人声提取的收益主要不在“把 SI-SDR 再刷高”，而在第 3.2 节：它会把
  没有人声的时间-频率格直接压到地板，而 v2.7 只做结构判断。
- 和 v2.7 的 30 对 held-out 不是同一批，只能表内比较。
- v3.3.2 的“谐波保护”修掉一个边缘情况：VAD 漏掉低电平语音尾巴时，
  `p232_266` 的 SI-SDR 会从 14.7 掉到 8.5；修复后回到 14.5，
  原 30 对 speech 均值 13.52 → 13.72。

### 3.1b 回到原 30 对协议

用 `results_pesq_stoi.csv` 里那 30 对（48k 源重采样到 16k）复测：

| 方法 | SI-SDR | PESQ-WB | STOI |
|---|---|---|---|
| v2.7 文档（原 16k 文件） | 13.92 | 2.505 | 0.9082 |
| 当前默认（频率优先 profile） | 13.51 | 2.456 | 0.9118 |
| 当前默认 + 关闭 profile（v2.8 行为） | **13.92** | 2.499 | **0.9082** |
| **人声提取 v3.3.2** | 13.72 | 2.439 | 0.9128 |

结论很直接：**降噪本身的分数没有提高**。当前默认比 v2.7 文档低 0.41 dB，来自
v2.9 的四视角 profile（“频率优先”用 SI-SDR 换 STOI），把 profile 切到
“关闭（v2.8）”就精确回到 13.92 / 2.499 / 0.9082。3.3 动的是新模式，不是旧模式。

### 3.2 非人声抑制（合成素材，8 s，强度 0.8）

| 输入 | 输出衰减 | 说明 |
|---|---|---|
| 纯音乐（和弦 + 贝斯 + 瞬态） | **−32.0 dB** | 音乐守卫判定“无音节”，整段落地板 |
| 谐波 drone（无音节） | −5.7 dB | 有谐波、无音节，只压掉齿间与停顿 |
| 共振峰元音（人造） | −0.3 dB | 被当成“人声”保留（它确实像元音） |
| 白噪 | **−42.7 dB** | 无人声核心 → 全部落地板 |
| traffic | −10.4 dB | 低频隆隆声；NPSS 低频保护仍留一部分 |
| 干净语音单独输入 | SI-SDR **22.25 dB** | 基本无损（PESQ 见 JSON） |

### 3.3 语音 + 音乐（0 dB 混合，6 个文件）

| 方法 | SI-SDR |
|---|---|
| noisy | −0.02 |
| 人声提取 | **+2.93** |

+3 dB 来自“静音段音乐被压掉 + 浊音段只留谐波梳”。音乐在语音**下方**同时
发声时，单通道纯 DSP 无法把与语音谐波重合的部分分开——这是本方法的边界，
不是调参能解决的。

## 4. 边界

- **单通道、无模型**：不做声源定位，也不做说话人辨识；所有人的语音都保留
  （babble 里别人的话也会被保留）。
- **音乐在语音下方**：只能压掉不重合的谐波和停顿段，不能保证“全部消失”。
  纯音乐/纯噪声素材可以整段压到地板。
- **16 kHz 分析**：8 kHz 以上不参与人声判断；48k 输入会先降采样分析，
  输出沿用 16k 的分析带宽。
- 纯 DSP 的人声/音乐判别是启发式，不是分类器；换了音乐风格，数字会变。

## 5. 复现

```bash
# 需要 clean/noisy 成对目录；PESQ/STOI 可选
python scripts/eval_voice_sep.py \
    --clean data/val16/clean --noisy data/val16/noisy \
    --limit 24 --strength 0.8 --out results_voice_sep.json
```

脚本会打印 4 种方法的 SI-SDR/PESQ/STOI、5 类非人声的衰减、干净语音的保真度，
并写出 JSON。

处理后日志会打印提取到的特征：

```
人声特征：F0 122 Hz，浊音 68%，语音段 54%，F1≈520 F2≈1480 Hz
```
